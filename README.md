# Caderno de Erros

Questões de concurso erradas viram flashcards, organizados por matéria e assunto e revisados por repetição espaçada.

- `cards.json`: os cards (frente, verso, dispositivo, macete, questão de origem, gabarito e comentário).
- `index.html`: o site (consulta, revisão espaçada, painel e backup).

O progresso de revisão fica salvo no navegador e, quando o site é aberto pelo Claude, também na conta.
